## 5. Cometes

Executa:

```
$servidor = "SRV01"
```

Després:

```
Write-Host "Servidor: $servidor"
```

i:

```
Write-Host 'Servidor: $servidor'
```

Respon:

**Quina diferència observes? Per què creus que passa?**
---
Cometes dobles es mostra Servidor: SRV01, perquè PowerShell interpreta el text i substitueix $servidor pel seu valor. Amb cometes simples es mostra Servidor: $servidor, perquè el text es pren literalment i no s'interpreta cap variable.

## 6. Guardar el resultat d'una ordre

Executa:

```
$serveis = Get-Service
```

Després:

```
$serveis
```

Respon:

- Què creus que conté $serveis? Conté el resultat de Get-Service, és a dir, la llista de tots els serveis de l’equip, cada servei és un objecte amb el seu nom, el seu estat (en execució o aturat) i altres propietats.
- La variable conté un únic valor o diversos elements? Diversos elements, un per cada servei de l’equip, ho pots comprovar amb $serveis.Count, que et diu quants n’hi ha.

Fes el mateix amb:

```
$processos = Get-Process
```

i comprova el seu contingut.

<img width="710" height="653" alt="image" src="https://github.com/user-attachments/assets/87d2bc66-2b57-412c-950c-1b09b3db346f" />

Passa el mateix amb $processos, que conté un element per cada procés en execució.

## 7. Aplicació a administració

Crea una variable:

```
$nomServei = "Spooler"
```

Utilitza aquesta variable per consultar el servei amb:

```
Get-Service -Name ...
```

L'objectiu és obtenir el mateix resultat que:

```
Get-Service -Name Spooler
```

però **sense escriure `Spooler` directament en el cmdlet**.

<img width="421" height="238" alt="image" src="https://github.com/user-attachments/assets/5700543e-c323-401d-b7f6-6a9757db2952" />

Les dues ordres donen el mateix resultat, però la segona no escriu Spooler dins del cmdlet: el valor surt de la variable $nomServei.
