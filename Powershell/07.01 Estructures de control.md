# Conclusions

Explica amb les teves paraules:

1. Què representa la variable `$servei` en:
```powershell
$serveis = Get-Service
foreach ($servei in $serveis) {
    ...
}
```
Representa cada servei de la colleccio "$serveis", un a cada volta del bucle, cada vegada que el bucle s'executa, "$servei" és el servei actual.

2. Quina diferència hi ha entre `foreach` i `ForEach-Object`? El "foreach" es una instrucció del llenguatge, recorre una colleccio que ja tenim guardada i fa servir una variable que triem nosaltres ($servei). El "ForEach-Object" es un cmdlet que utilitza dins d'un pipeline que rep els objectes d'un en un i els anomena "$_".

3. Què representa `$_` dins de `ForEach-Object`? El "$_" es objecte actual, el que en aquel moment ha arribat pel pipeline a ForEach-Object.
