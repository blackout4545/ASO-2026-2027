# Pipeline

## 1. Primer pipeline

Executa:

```powershell
Get-Service
```

Ara executa:

```powershell
Get-Service | Sort-Object Name
```

Respon:

1. Quina diferència observes entre les dues sortides? La primera sortida mostra els serveis en lordre en que Get-Service els retorna. La segona els mostra ordenats alfabeticament pel camp Name.
2. Què fa la part situada abans de `|`? Es "Get-Service" obte la llista de serveis.
3. Què fa la part situada després de `|`? Es "Sort-Object Name" agafa aquesta llista i l'ordena pel nom.
4. `Sort-Object` crea els serveis o rep serveis creats per una altra ordre? no crea els serveis si no rep els que ha creat una altra ordre.
5. Quina ordre és la que genera inicialment les dades? EL "Get-Service" és la que genera les dades.

Fes ara la prova:

```powershell
Get-Service | Sort-Object Status
```

Què ha canviat? Els serveis queden agrupats per estat, primers es "Stopped" i segons "Running" amb "-Descending" ordre inverteix i surten primer que es Running.

Finalment:

```powershell
Get-Service | Sort-Object Status -Descending
```

Explica amb les teves paraules què ha fet el pipeline.

el pipeline agafa el que genera la primera ordre (exemple Get-Prosses) i ho passa a la segona (exemple Sort-Object Status) per transforma per mostrar el resutat del pipeline.


```powershell

```

```powershell

```

Respon:

1. Obtenen el mateix resultat? Sí, te el mateix resultat.

La variable es una copia del aquell moment i no s'actualitza, mentre que Get-Service consulta l'estat actual.
3. En quin cas s'ha guardat prèviament la informació en una variable? el "$serveis | Sort-Object Name"


## 3. Construir un pipeline pas a pas

Executa primer:

```powershell
Get-Process
```

Ara:

```powershell
Get-Process | Sort-Object CPU
```

Finalment:

```powershell
Get-Process |
    Sort-Object CPU |
    Select-Object -First 5
```

No continuïs fins haver observat el resultat de cada ordre.

Completa:

| Pas | Ordre | Què entra? | Què surt? |
|---|---|---|---|
| 1 | `Get-Process` | ... | Tots els processos |
| 2 | `Sort-Object CPU` | Gafa els tots els processos | Ordenats per CPU de menys a més |
| 3 | `Select-Object -First 5` | Els processos ordenats | Només els 5 primers, que són els que tenen menys CPU |

Explica què passaria si eliminéssim:

Passaria que Select-Object -First 5 agafaria directament els cinc primers processos de la llista de Get-Process, sense ordenar-los abans per CPU.

```powershell
Sort-Object CPU
```

del pipeline.

Comprova-ho executant:

```powershell
Get-Process | Select-Object -First 5
```

Els cinc processos obtinguts són necessàriament els que consumeixen més CPU? No.

Explica per què.

Són només els cinc primers de la llista, i l’ordre en que surten no depen del consum de CPU. Poden ser processos gairebe inactius, mentre que els que gasten mes queden mes avall.

## 5. Canviar l'ordre del pipeline

Executa:

```powershell
Get-Process |
    Sort-Object CPU -Descending |
    Select-Object -First 5
```

Ara executa:

```powershell
Get-Process |
    Select-Object -First 5 |
    Sort-Object CPU -Descending
```

Respon:

1. Les dues ordres fan el mateix? No fan el mateix.
2. Per què? A la primera, s'ordenen tots els processos i despres es queden els cinc amb més CPU. A la segona, primer es queden
cinc processos qualssevol (els primers de la llista) i despres només s'ordenen aquests cinc.
4. Quants processos arriben a `Sort-Object` en el primer cas? En el primer cas arriben tots els processos del sistema.
5. Quants processos arriben a `Sort-Object` en el segon? En el segon cas arriben només 5.

Aquest exercici és important: **l'ordre dels cmdlets dins del pipeline modifica el resultat**.
