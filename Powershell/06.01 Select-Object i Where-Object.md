## 5. Entendre `$_`

Utilitza:

```
$numeros = 5, 20, 3
```

i analitza:

```
$numeros |
    Where-Object { $_ -gt 10 }
```

Completa:

|Valor de `$_`|Resultat de `$_ -gt 10`|Passa el filtre?|
|---|---|---|
|5|No|No|
|20|Si|Si|
|3|No|No|

Explica amb les teves paraules:

**Què representa** `$_`**?** Es el valor que "Where-Object" esta mirant en aquell moment que els numeros passen d’un en un per exemple primer el 5, despres el 20 i despres el 3. I finalment depen que em escolit quin operador has utilitzat.

Executa-la després d'afegir cada nova etapa i observa com va canviant el resultat.

Representa finalment el recorregut:

```
Get-Process
     ↓
Where-Object { $_.CPU -gt 5 -and $_.Id -gt 1000 }
____________
     ↓
Sort-Object CPU -Descending
____________
     ↓
Select-Object -First 5
____________
     ↓
Select-Object Name, Id, CPU
____________
```

Indica què entra i què surt de cada etapa.

Etapa 1: "Get-Process" no rep res i genera tots els processos.
Etapa 2: "Where-Object" rep tots els processos i nomes en deixa passar els que tenen CPU > 5 i Id > 1000 (més gran que X).
Etapa 3: "Sort-Object CPU -Descending" rep els processos filtrats i els retorna ordenats de major a menor CPU.
Etapa 4: "Select-Object -First 5" rep els processos ordenats i nomes en retorna els cinc primers.
Etapa 5: "Select-Object Name, Id, CPU" rep aquests cinc processos i els retorna amb nomes les propietats Name, Id i CPU.

# 10. Conclusions

Explica amb les teves paraules:

1. Per a què serveix `Select-Object`? Per triar que es mostra, quines columnes i quantes files.
    
2. Quina diferència hi ha entre seleccionar **objectes** i seleccionar **propietats**? Els objectes són les files i les propietats són les columnes.
    
3. Quina diferència hi ha entre `Get-Member` i `Select-Object *`? "Get-Member" diu quines propietats té un objecte i el "Select-Object *" les mostra amb el seu valor.
      
4. Per a què serveix `Where-Object`? Per fer filtrarga nomes deixa passar el que compleix una condicio o varis condicions (dins del "{}").
    
5. Què representa `$_`? I `$_.CPU`? "$_" es l'objecte actual i "$_.CPU" es la CPU aquest objecte.
    
6. Què passa amb un objecte quan la condició de `Where-Object` retorna `True`? I quan retorna `False`? Si es True, passa a l'etapa seguent. Si es False es descarta.
     
7. Explica què entra, què surt i què fa cadascuna de les etapes:
```
Get-Process |
    Where-Object {
        $_.CPU -gt 10 -and $_.Id -gt 1000
    } |
    Sort-Object CPU -Descending |
    Select-Object -First 5 Name, Id, CPU
```
- Get-Process: genera tots els processos.
- Where-Object: deixa nomes els que tenen CPU > 10 i Id > 1000.
- Sort-Object: els ordena de mes a menys CPU.
- Select-Object: es queda amb cinc i mostra nomes Name, Id i CPU.
